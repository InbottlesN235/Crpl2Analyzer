# 更新日志

本项目遵循「主版本.次版本.修订号」，每次改动都会同步更新 exe 的 FileVersion。

## v1.4.0 — 2026-11-22

**X-Acc 曲线改用官方双曲线模型**

- 拿到 TUF 官方曲线编辑器截图：曲线是过 `(95%, 基础分)` 与两个内点的双曲线，
  参数为 `Pole offset (E)` / `Top multiplier (G)`。
- 新增「锚点①／②（准度, 分数）」+「拟合官方曲线」：按 `y = A + B/(x - C)` 精确拟合，
  并显示极点与顶端倍率。
- 用官方截图里的两个 pin 反推：`C = 1.00875`、`G = 3.7090×`，官方 `G = 3.7117×`（误差 0.07%）。
- 右侧新增「分数 vs 准度（95%→100%）」曲线图，绿点标当前准度；未拟合时退回指数模型。

## v1.3.5 — 2026-11-22

**按官方文档（How scoring works 原文）对齐**

- 速度倍率 150%–200%：官方表述是 "Scales toward 1×"，改为 0.65 → 1.00 线性插值（原先按 1.00 处理）。
- 结果卡新增 **U13+ 官方参考分**显示：U13 20k/30k、U14 30k/40k、U15 50k/60k、U16 60k/70k。
- 文案改为官方口径：X-Acc 曲线「在 100% 准度处陡增」（PP 断点）。
- README 补充 Ranked Score 公式（Σ Sₖ × 0.9^(k-1)，同谱只取最高分）。

## v1.3.4 — 2026-11-22

**新增**

- 「评分估算」支持**按谱面校准**：填入该谱在 TUF 上的实测分数 → 反解曲线指数 n 并套用。
- 补充三局实测对照（First Town 89.20 / Lovelight 89.06 / End of Time 40.09），
  校准后程序估算与官方完全一致；同时确认 PP 倍率与曲线是逐难度/逐谱面设定的。

## v1.3.3 — 2026-11-22

**修复**

- 评分估算严重偏低（P17 99.31% 估成 33，TUF 实际 89.20）：原因是把 **X-Acc 倍率按 1.0** 计。
  官方满准度倍率至少 6× 且随难度上升，旧逻辑直接漏掉了这一项。
- 改为 `X-Acc 倍率 = PP 倍率 × 准度^指数`（默认 PP=6.00、n=114.7，可手改/手填）。
  用该局实测校验：`30 × 6 × 0.993072^114.7 × 1.1 = 89.20`，与论坛分数一致。
- 评分页新增 X-Acc（%）、PP 倍率、曲线指数三个输入；X-Acc 与准度一样随回放自动同步，
  且保留完整精度（不再被两位小数截断）。

## v1.2.1 — 2026-11-16

**界面**

- 判定档位按 ADOFAI 3.4.0 结算画面的文案改名，并从快到慢排列：
  v3 为 `提前 / 太快 / 稍快 / -完美 / x完美 / +完美 / 稍慢 / 太慢 / 太晚 / 错过`；
  v2 为 `提前 / 太快 / 稍快 / 完美 / 稍慢 / 太慢 / 太晚 / 错过`。
- `x完美` 对齐 ±12.5° 的 XPerfect 窗口；`+完美` / `-完美` 是同一段完美窗被 XPerfect 切开后的早/晚两侧（按使用习惯，`+` 在早侧）。
- 命名与槽位用一局真实回放（`First Town Of This Journey`）逐位核对：
  `JudgmentList = 0,10,10,131,1559,74,11,2,0,…` 对应结算画面的
  `提前0 / 太快10 / 稍快10 / 完美1764(=131+1559+74) / 稍慢11 / 太慢2`。

**修复**

- 判定窗的「有效」最小时间由 65ms 修正为 40ms，`Pure` 由 20ms 修正为 25ms（按真实回放拟合）。
- 每击的分类改用**逐击实际角速度**（`|角度误差| / |时间误差|`）计算窗口：谱面行星变速时，
  用标称 BPM 会把窗口算窄（`bpm=340` 但实际 680 的谱面此前完全错档）。
- 逐击判定改为「按文件档位计数校准」：按归一化误差排序后依 `JudgmentList` 切档，
  保证逐击分布与文件自洽，末值 X-Acc 与 `percentXacc` 相等（示例：99.3072% 对 99.3072%）。
- 精准度分母排除槽 14/15（游戏侧同样不计），`准度损失分解` 不再把这类计数算成损失。
- 「早/晚平衡」「损失分解」「分段 X-Acc」等处的判定名改为跟随这张命名表，不再硬编码。

**许可**

- 改为 GPL-3.0-or-later，版权人 InbottlesN235；源文件加上 SPDX 头。

**修复**

- 鼠标扫过顶部导航条时整条区域闪烁：自绘面板（导航 / 标题栏 / 状态栏）改为双缓冲、绘制合并进 `WM_PAINT`；
- 悬停切换标签时只重绘受影响的两个标签区域，不再重绘整条导航。

## v1.2.0 — 2026-11-16

**新增**
