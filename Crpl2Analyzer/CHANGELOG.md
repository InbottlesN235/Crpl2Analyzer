# 更新日志

本项目遵循「主版本.次版本.修订号」，每次改动都会同步更新 exe 的 FileVersion。

## v1.2.1 — 2026-11-16

**许可**

- 改为 GPL-3.0-or-later，版权人 InbottlesN235；源文件加上 SPDX 头。

**修复**

- 鼠标扫过顶部导航条时整条区域闪烁：自绘面板（导航 / 标题栏 / 状态栏）改为双缓冲、绘制合并进 `WM_PAINT`；
- 悬停切换标签时只重绘受影响的两个标签区域，不再重绘整条导航。

## v1.2.0 — 2026-11-16

**新增**

- 「X-Acc 曲线」页：由逐次角度误差反推每一击的判定，绘制累计 X-Acc（含最近 N 击滑动曲线）与误差柱状背景；
- 分段 X-Acc（整局切 8 段）与「反推校验」卡片（文件 `JudgmentList` / `percentXacc` 对照）；
- 逐次误差 CSV 增加 `judgment / weight / xacc_after_hit` 三列。

**说明**

- 判定窗按 ADOFAI 口径计算：`XPerfect = max(12.5°, 16.67ms×BPM×3)`，`Pure = max(30°, …)`，`Perfect = max(45°, …)`，`Counted = max(60°, …)`；
- 示例文件反推的逐击判定与文件内判定汇总逐槽位一致，末值 X-Acc 与 `percentXacc` 完全相同。

## v1.1.0 — 2026-11-16

**新增**

- 支持 `CRP4` 容器 / `formatVersion 3`（Creplay 2.17、ADOFAI 3.4.0）；
- 判定槽位扩到 16 档，自动识别 `完美- / X完美 / 完美+`；
- 「误差」页：逐次命中误差散点（含 ±12.5°/±30°/±45°/±60° 判定窗色带）、误差分布直方图、误差统计；
- 由角度误差与时间误差的比值反推 BPM（官方关回放里 `bpm` 字段为 0）；
- 导出逐次误差 CSV。

**修复**

- 判定枚举按 ADOFAI 3.3.1 源码校正（旧版的第 7 槽是 Multipress，不是 Miss）。

## v1.0.0 — 2026-11-16

首个版本。

- `CRP2` / `formatVersion 2` 解密与解析；
- 总览、准度分布（判定柱状、环形、早/晚平衡、损失分解）、时间轴（密度、分段、累计）、按键（键位、间隔、双压、迁移热图）、对比、数据；
- 多文件对比、拖放、导出 PNG / JSON / CSV；
- 单文件 exe，零运行时依赖（Windows 10/11 自带 .NET Framework 4.8）。
